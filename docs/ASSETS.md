# Preview asset provenance

`preview.png` captures the actual LensLink QML panel using Qt's item capture.
For capture only, its displayed image and values were substituted with a
synthetic feed and illustrative connection data. The capture is marked
"example". No actual phone IP, camera frame or desktop background is shown.
These substitutions and the capture hook are not part of the released plugin.
The installed production panel was restored after capture.

`assets/synthetic-meeting-feed.png` is the same wooden mannequin in a fictional
office used by the owner's Anker C200 plugin. It was originally generated for
that project with OpenAI image generation; it depicts no real person or private
room. The owner may redistribute the image under this repository's MIT license.
No OBS source, crop, connection setting or broadcast output was changed to
produce the preview.
